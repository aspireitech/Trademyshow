Do you need to pay for AI?

No subscription is required, and the product runs with no AI key at all — the template writer produces the insight instead. Keys buy better prose, not the numbers, which are always computed by your own engine.

ProviderFree tierRole hereVerdict
Google Gemini Yes — free tier with rate limits Primary Start here
Anthropic Claude No — pay-as-you-go credits First backup Optional
OpenAI No — pay-as-you-go credits Second backup Optional
No key at all Free Template writer Works today

Failover only fires on failure. Gemini serves every request until it returns a quota error; that provider then goes into cooldown and the next key takes over. Backups cost nothing while the primary is healthy — so adding a paid key is insurance, not a running expense.

Does it use the latest news?

The pipeline is built and news carries 30% of every Insight Score — headlines are matched to each holding, weighted by estimated impact, and fed into both the score and the written explanation. What is not real yet is the feed: today it is a deterministic mock so the app runs and tests without API keys. Connecting a live provider is a contained change behind an existing adapter, and it is on the blocker list above.

Suggested order

Phase 1 · 2–3 weeks

Make it real

Live market and news feeds, Stripe checkout and webhooks, hosting, CI. Without these there is nothing to sell.

Phase 2 · 1–2 weeks

Make it safe

Password reset, email verification, rate limiting, headers, CSRF, deletion, Terms and Privacy.

Phase 3 · ~2 weeks

Make it stick

Scheduled email digests, alerts, onboarding polish, admin panel. The daily habit is the product.

Phase 4

Make it grow

Referrals, promo codes, multi-asset coverage, analytics, social login.

Two items are routinely underestimated. Password reset — someone will lock themselves out on day one, and there is currently no recovery path. Scheduled email — without it people simply forget to return, which is exactly the churn pattern visible in the competitor numbers you shared.
